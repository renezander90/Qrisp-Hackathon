# Qrisp Hackathon: Block Encoding Mastery

A hands-on notebook for learning [Qrisp](https://qrisp.eu)'s `BlockEncoding` framework, taking you from classical linear algebra to quantum algorithms.

## Challenges

| # | Challenge | Topic |
|---|-----------|-------|
| 1 | The Quantum Calculator | Block-encoding arithmetic (`3A - B²`) and Repeat-Until-Success |
| 2 | Resource-Efficient Hamiltonians | LCU construction vs. `from_array`: gate count and depth |
| 3 | Quantum Linear Systems | Solving `Ax = b` with `.inv()` |
| 💀 | Quantum Recommender System | Polynomial spectral filtering with `.poly()` |
| 💀 | Bonus: Ground State Preparation | Filtering a Heisenberg model toward its ground state |
